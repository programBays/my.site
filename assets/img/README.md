# Фото для сайта

Положи сюда файлы с такими именами — сайт подхватит их сам:

| Файл | Где на сайте | Размер |
|---|---|---|
| `portrait-mini.jpg` | Hero, маленькая карточка «12 лет» | квадрат, от 300×300 |
| `portrait.jpg` | Блок с цитатой | вертикальное, от 600×760 |
| `office.jpg` | Большая карточка «Онлайн по всему миру» | горизонтальное, от 1200×900 |

Красную тонировку для `portrait-mini.jpg` и `office.jpg` сайт делает сам.
Для превью в соцсетях положи `assets/og-image.jpg` (1200×630).
